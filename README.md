# Reelax Billing Page

Billing and checkout UI built with React + Tailwind CSS.

## Setup

```bash
npm install
npm run dev
```

## Tech used
- React 18
- Tailwind CSS
- Lucide React (icons)
- Vite

## Features
- Billing info form with state/city cascade
- Order summary with wallet & coupon support
- Live price calculation with 18% GST
- Fully responsive
